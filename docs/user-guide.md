# 用户手册

1. 在“导入资料”上传 PDF、Markdown、文本或代码，或填写公开 GitHub URL。
2. 等待数据源状态从 `pending/running` 变为 `completed`。失败时卡片显示具体原因。
3. 输入技术问题，选择 Agentic 或 Naive。Agentic 会规划并可重写查询；Naive 只
   做一次语义检索。
4. “Agent 路径”实时展示节点和工具；运行结束后“检索详情”显示耗时与结果数。
5. 点击报告中的 `[S1]` 打开证据抽屉，核对原文、定位符和检索分数。
6. 报告标注“证据不足”时，应导入更相关资料或缩小问题，而不是把内容当作事实。

Issue 导入需要访问 GitHub API。没有 Token 时限额较低；代码克隆与 Issue 索引
分开记录，错误不会伪装成空结果。
