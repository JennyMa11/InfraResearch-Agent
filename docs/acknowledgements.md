# 第三方项目与致谢

设计参考而非代码复制：

- [LangGraph Agentic RAG](https://docs.langchain.com/oss/python/langgraph/agentic-rag)：
  Router、检索、证据评价和有界循环模式。
- [Open Deep Research](https://github.com/langchain-ai/open_deep_research)：
  研究任务状态与可配置检索边界。
- [Kotaemon](https://github.com/Cinnamon/kotaemon)：引用预览和低相关性提示。
- [Qdrant Client](https://github.com/qdrant/qdrant-client)：Local 与服务端一致 API。
- [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) 和
  [vLLM](https://docs.vllm.ai/)：本地 OpenAI-compatible 推理与指标。
- [FastEmbed](https://github.com/qdrant/fastembed) 和
  [multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small)：
  基于 ONNX 的多语言语义向量。
- [Model Context Protocol](https://modelcontextprotocol.io/)：v0.2.0 接口方向。

运行时依赖的许可证以各自发行包为准；发布二进制或镜像前应生成并审核 SBOM。
